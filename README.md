# PENJOY-бот (Telegram) — лид-магнит, заказы, автоворонка

Реализация воронки из `../FUNNEL.md` §4: раздаёт гайд и электронные номера,
сегментирует контакта, собирает заказы (оплата по СБП), ведёт дожим
дни 3/7/14/21/30 и уведомляет админа о заказах и вопросах.

Стек: Python 3.11+, aiogram 3, SQLite. Хостинг: **bothost.ru**.

## Структура

```
penjoy-bot/
├── bot.py           # точка входа: хендлеры, FSM заказа, цикл дожима
├── config.py        # настройки (всё с пометкой ЗАМЕНИТЬ)
├── texts.py         # тексты воронки
├── kb.py            # клавиатуры
├── db.py            # SQLite: пользователи, заказы, дожим, остатки
├── requirements.txt # aiogram
└── files/           # PDF для раздачи (см. files/ЧТО-ПОЛОЖИТЬ-СЮДА.md)
```

## Перед деплоем (10 минут)

1. **@BotFather** → `/newbot` → токен (его же вставите на Bothost).
2. **config.py → ADMIN_ID** — свой Telegram ID (узнать: @userinfobot).
   Сюда приходят заказы и вопросы.
3. **config.py → SBP_PHONE, SBP_NAME, SBP_BANK** — реквизиты для оплаты.
4. **config.py → STOCK_DEFAULT** — фактическое распределение 25 экз.
   по номерам (или потом командой `/setstock 1 8`).
5. **files/** — положить `gayd.pdf`, `issue1.pdf` … `issue8.pdf`
   (и `checklist.pdf` — по желанию).

**Секреты в Git не закоммичены:** `.env` в `.gitignore`; шаблон —
`.env.example`. При деплое из Git-репозитория
**github.com/ermlv/penjoy-consultant** токен `BOT_TOKEN` платформа Bothost
подставляет автоматически, `ADMIN_ID` зашит в `config.py` по умолчанию.
Для локального запуска скопируйте `.env.example` в `.env` и впишите токен.

## Деплой на bothost.ru

1. Зарегистрируйтесь → [Создать бота](https://bothost.ru/create-bot.php):
   платформа **Telegram**, библиотека **Python (aiogram)**, вставьте
   Bot Token.
2. Код загрузите одним из способов:
   - **Git (основной):** репозиторий `github.com/ermlv/penjoy-consultant`,
     ветка `main`. Пуш в ветку = авто-деплой на Bothost;
   - **zip-архивом**: запаковать содержимое папки `penjoy-bot` в `.zip`
     (bot.py в корне архива) и загрузить в панели.
3. Главный файл: `bot.py` (автодетект, но проверьте в настройках).
4. **Тариф:** бесплатный Starter подойдёт для теста, но база SQLite
   стирается при рестарте контейнера. Для работы берите **Basic (99₽/мес)** —
   там постоянный диск. Заказы в любом случае не теряются: каждый дублируется
   сообщением вам в Telegram.
5. Если на тарифе доступны «Переменные окружения», добавьте `ADMIN_ID`
   (BOT_TOKEN Bothost подставляет сам).
6. Запустить и смотреть **Логи** — бот пишет остатки на старте.

База создаётся автоматически в `/app/data/penjoy.db` (требование Bothost —
папка `data` переживает обновления кода). Папка `data/` в `.gitignore`.

## Как проверить (чек-лист)

1. `/start avito` — приветствие про Avito, вопрос сегментации.
2. Нажать «🌱 Выбираю первую» — прилетели гайд + №1, затем оффер с остатками.
3. Написать «номер 5» — прилетел PDF №5.
4. «📦 Заказать печатный» → номер → количество → доставка → имя → адрес →
   телефон → сводка → «✅ Всё верно» → реквизиты СБП.
5. «✅ Я оплатил» — вам пришло уведомление; подтвердите: `/confirm <id>`.
6. Проверьте `/stock`, `/setstock 3 7`, `/stats`, `/export`.
7. Нажмите «Отписать от напоминаний» с любого сообщения дожима —
   напоминания остановились.

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/start [avito\|vk\|tg\|site\|ref]` | всем | вход в воронку с меткой источника |
| `/stock` | всем | текущие остатки тиража |
| `/setstock N Q` | админ | остаток номера N = Q экз. |
| `/stats` | админ | контакты / заявки / оплаты / выручка |
| `/confirm ID` / `/reject ID` | админ | подтвердить/отклонить оплату |
| `/export` | админ | CSV: пользователи + заказы (для KPI) |

## Автоворонка дожима

Раз в час бот проверяет контактов и шлёт касания на дни 3, 7, 14, 21, 30
(тексты — FUNNEL.md §4, ветка по сегменту на дне 3). Останавливается:
после оплаты (кнопка или `/confirm`) и по кнопке «Отписать от напоминаний».
На дне 30 — предложение оставить email (новый номер ~раз в год).

## Частые проблемы

- **«Conflict: terminated by other getUpdates»** — бот запущен ещё где-то
  (локально или второй контейнер). Оставьте один экземпляр.
- **«Unauthorized»** — неверный токен в BotFather/Bothost.
- **Бот молчит** — смотрите Логи в панели; чаще всего ошибка в зависимостях
  (есть `requirements.txt`) или не тот главный файл.
- **Пропала база** — на Starter это норма при рестарте; данные живут в
  `/app/data`, перенеситесь на Basic.
